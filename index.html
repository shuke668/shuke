From prompt to picture

AI 制作流程全记录

先确定叙事，再把文字转成可执行的视觉提示词；生成素材后进入剪辑与检查。按以下顺序，就能复现本次作品的制作思路。

01

确定选题与标题

输入名著名称《红楼梦》，先让 AI 提炼主题，生成能统领全片的标题。本片使用“红楼一梦：大观园的繁华与离散”，把人物群像与盛衰主题放在同一条叙事线上。

输入：名著名称
02

写成八段讲解脚本

根据标题梳理八个有代表性的情节，用“人物：事件”格式写成短句。顺序由初见和省亲进入园中日常，再转向抄检与离散，给后续画面生成一条清晰的情绪线。

输出：人物 · 事件
03

写详细画面提示词

把每句讲解扩写成静态画面说明：交代人物、姿态、服饰、环境、构图、光线和情绪，只描述一个瞬间。每段不少于五十字，并统一以“真实古代纪录片风格”收尾。

原则：单一画面 · 可视细节
04

并行生成八张配图

将八条画面提示词分别提交给图像生成工具并行制作，尺寸设为 1K、画幅设为 9:16。生成后按情节编号保存到“图片”文件夹，方便逐段对应脚本。

参数：1K · 9:16
05

撰写视频提示词

参考每张已生成配图，为该幕编写视频提示词，描述人物微动作、环境变化、镜头运动与氛围；提示词落到当前画面，保持人物造型和场景连贯，并按素材编号归档。

依据：配图 · 镜头动势
06

生成片段并检查

以图片作为首帧参考，采用首尾帧思路并行生成视频片段。可选的 DeepSeek Flash 视频路线同样按 1K 与 9:16 设定；本次 API 调用遇到失败，随后改用 Workbuddy 自带的生图、生视频能力继续制作。

异常处理：切换内置生成能力
07

在剪映中整理草稿

按故事顺序导入画面素材，组织片段与转场，补齐字幕和音频，整理成一条完整时间线并保存为草稿。文件夹分为“剧本、图片、视频”三个子文件夹，素材各归其位。

素材归档：剧本 / 图片 / 视频
08

复核并导出成片

逐段检查画面顺序、字幕显示和音频是否齐备，再播放完整时间线确认衔接。第一次剪映草稿缺少字幕和音频；调整提示词并修改、复查之后，才得到当前这版完整作品。

复核重点：字幕 · 音频 · 完整播放
制作中遇到的问题

API 调用失败：原计划的生成接口未能完成调用，因此改用 Workbuddy 自带的生图与生视频功能继续。
草稿缺少字幕和音频：第一次在剪映里生成的草稿只有画面，没有配备字幕和音频。修改提示词、调整流程后重新检查，补齐字幕与音频，最终草稿才达到预期。这个检查点也被列入复核步骤，避免只看画面、不检查完整播放体验。

Edit & organize

剪映整理与素材目录

把八幕内容变成一支可以完整观看的短片，关键是让画面、字幕和音频沿着同一叙事顺序工作，并把工程素材整理清楚。

剪映草稿整理要点

草稿整理按剪辑任务安排素材：导入八幕片段并按故事顺序排布，检查字幕与讲解是否对应，添加音频后从头到尾播放一遍。第一次草稿缺少字幕、音频，调整后再复核。剪映 API 文档作为参考入口，具体操作依据本次制作记录。

顺序：八幕叙事检查：字幕同步检查：音频完整本页交付：MP4 + 配图 + 提示词
